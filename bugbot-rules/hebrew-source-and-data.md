# hebrew-source-and-data

זהה מקומות שבהם טקסט עברי — בהערות, בסודות, בכותרות או בחיפוש — נופל
על הנחות ASCII של הכלים והספריות.

## דווח כשמתקיים אחד מהבאים

1. תווי בקרה BiDi בלתי נראים בקבצי מקור: `U+200E`, `U+200F`,
   `U+202A`-`U+202E`, `U+2066`-`U+2069`. הם מפילים את bandit ב-B613
   (Trojan Source) ואת ruff ב-PLE2502. נכנסים בהעתקה מדפדפן או מצ'אט,
   ואינם נראים בשום עורך.

2. `secrets.compare_digest` על ערך שיכול להכיל תווים לא-ASCII (סוד
   מ-ENV, מקונפיג, או מ-DB). הפונקציה זורקת TypeError במקום להחזיר
   False — כלומר האימות עצמו נופל.

3. ערך שנוסע בכותרת HTTP (`Authorization`, `X-*`) בלי ולידציה שדורשת
   ASCII. כותרות הן latin-1; תו עברי או אמוג'י נשבר בצד הלקוח לפני
   שהגיע לשרת, ולכן לא יופיע בלוגים.

4. חיפוש טקסט בעברית בלי נורמליזציה של ניקוד. המשתמש יסיק שהחיפוש
   שבור.

5. הודעת שגיאה טכנית באנגלית שמוחזרת למשתמש קצה — גם חוויה גרועה וגם
   דלף מידע. הודעה גנרית בעברית למשתמש, הפרטים ללוג.

## False positives

- מחרוזות עברית בתוך תבניות HTML או קובצי תרגום — שם זה תקין ורצוי.
- בדיקה שמחפשת את תווי ה-BiDi בעצמה, אם היא כותבת אותם כ-escape.

## חומרה

MEDIUM — לא מגיע לפרודקשן ברוב המקרים, אבל מפיל CI ומפיל אימות,
וההודעות מהכלים לא מכוונות לסיבה האמיתית.
