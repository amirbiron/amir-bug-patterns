# linter-fix-changes-runtime-behavior

זהה שינוי שנעשה **רק** כדי להשתיק בדיקה סטטית, ושנגע בסדר, במיקום או בתוכן של קוד שרץ. הבדיקה הסטטית אינה יודעת מה קורה בזמן ריצה, ולכן היא מרוצה גם כשהשינוי שבר משהו — והמשוב שלה מיידי וחד-משמעי בדיוק כמו שהמשוב האמיתי אינו.

## דווח כשמתקיים אחד מהבאים

1. **ייבוא שהוזז לראש הקובץ כדי לספק E402 / `import-outside-toplevel`**, בקובץ שמכין משהו לפני הייבוא — `sys.path`, משתני סביבה, `load_dotenv`, monkeypatch, או `django.setup()`. הסימן: הערה בקובץ שמסבירה למה הייבוא נמצא איפה שהוא. ‏`# noqa` עם הערה הוא הפתרון הנכון כאן, לא הפשרה.

2. **מחרוזת ששונתה כדי לנקות אזהרת escape** (`W605`, `invalid-escape-sequence`) — במיוחד כשהיא רג'קס. ‏`.format()` על תבנית שמכילה כמת חזרות מפרש אותו כשדה החלפה: ‏`"x{20,}".format(bs="\\")` **זורק `KeyError: '20,'`** — נבדק — כלומר הכשל קורה בזמן ה-`format`, לפני שהרג'קס בכלל נבנה. מה שקורה משם והלאה תלוי במי תופס: מודול שנטען בעלייה ייפול ברעש, אבל בנייה עצלה בתוך `try` מותירה את הצרכן **בלי המסנן** — וזו הצורה שבה "ניקוי אזהרה" הפך בפועל לכיבוי של מסנן סודות בלוגים. הכלל: תבנית עם `{` שאינו שדה החלפה אינה עוברת `.format()`; משרשרים, או מכפילים את הסוגריים.

3. **`except` שהורחב או שונה כדי לספק `bare-except` / `broad-except`** בלי שנבדק מה באמת נזרק שם.

4. **שם משתנה, פרמטר או סדר ארגומנטים ששונה בגלל כלל סגנון**, בקוד שנקרא דינמית (`getattr`, ‏`**kwargs`, ‏Pydantic, ‏ORM, סריאליזציה).

5. **קומיט שכל תוכנו lint** ושנוגע בקבצים שרצים בעלייה (`app.py`, ‏`main.py`, ‏`wsgi.py`, ‏`conftest.py`, ‏`__init__.py`).

## התיקון המומלץ

השתקה מקומית עם הערה שאומרת **למה** — היא מתעדת את התלות האמיתית, ולכן היא לא טלאי אלא תיעוד. ואם בכל זאת משנים את הקוד: הצורה החדשה צריכה לעבור בריצה את אותה בדיקה שהישנה עברה. בפרט, קובץ שרץ בעלייה — להעלות אותו פעם אחת בפועל.

## False positives

- שינויי lint בקוד טהור: לולאות, תנאים, מבני נתונים, טסטים.
- פורמוט אוטומטי (black, prettier) שאינו משנה סמנטיקה.

## חומרה

HIGH כשהקובץ רץ בעלייה או כשהמחרוזת היא בקרה (רג'קס של ניקוי סודות, ולידציה, הרשאה) — שני המופעים המתועדים הם בדיוק אלה: קריסת boot בלולאה, ומסנן סודות שהפסיק לעבוד. MEDIUM אחרת.
